# 闲鱼商品监控

在已登录闲鱼的 Chrome 中按关键词和价格区间监控商品，发现新的匹配商品时通知飞书群。支持多组独立条件、单独启停、商品 ID 去重及可选的飞书签名校验。

采用 Manifest V3 本地扩展。首次安装和新增条件的关键词均为空白，填写并保存后才能预览或开始。默认检测间隔为 10 分钟。

## 安装

1. 下载并解压本仓库，保留解压目录。
2. 在已登录闲鱼的 Chrome 个人资料中打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的 **extension** 文件夹。
4. 点击工具栏扩展菜单中的「闲鱼商品监控」，打开设置页。

运行需要 Chrome 120 或更新版本，无需安装依赖或执行构建。加载方法见 [Chrome 官方安装说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

## 配置监控条件

1. 填写商品关键词、可选的最低价和最高价、检测间隔，再点击「保存当前条件」。
2. 点击「预览匹配商品」核对结果。预览无需配置飞书。
3. 点击「新增监控条件」可添加其他目标，每组都有独立的价格、间隔、搜索标签和去重记录。
4. 使用顶部下拉列表切换条件，分别开始或暂停。修改某组条件前先暂停该组。删除会清除该组的本地去重记录。

关键词按空格拆分，标题须包含全部词，忽略大小写及全半角。连字符参与匹配，例如 `ZVE1` 和 `ZV-E1` 可能得到不同结果。价格支持两位小数，包含区间端点，任一价格栏可留空表示不限。标题匹配可能包含配件或其他关联商品，请先预览核对。

## 配置飞书通知

1. 在接收通知的飞书群设置中添加「自定义机器人」，可命名为「闲鱼商品监控」。
2. 开启自定义关键词校验时设置为 **闲鱼监控**，所有通知均包含这四个字。开启签名校验时还需填写该机器人的签名密钥。
3. 将 Webhook 地址粘贴到扩展密码输入框，点击「保存飞书设置」。多组条件共用此机器人，修改公共通知配置前需暂停全部监控。
4. 点击「发送测试消息」，到群中核对收件，再分别点击各组的「开始监控」。

保存地址后，输入框会清空并显示「已保存」。留空会保留已有值，勾选清除选项并保存可删除本地凭据。更换机器人地址时，应同时填写新机器人需要的签名密钥。接口格式及安全选项见 [飞书自定义机器人指南](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)。

## 检测与通知行为

- 点击开始后，扩展会自动打开该组的普通闲鱼搜索标签。运行时需保持 Chrome 和这些标签打开，可以放在后台，设置页可关闭。
- 每组首次成功扫描记录已有匹配商品，后续发现新的商品 ID 才通知。通知包含标题摘要、当前挂牌价和商品链接。
- 检测间隔为 5–1440 的整数分钟。后台每分钟最多处理一组到期条件，按计划时间先后错开执行，条件较多时会顺延。电脑休眠或浏览器调度也可能造成延迟。
- 每次定时检测先检查当前页面，再进行一次正常刷新，只读取当前结果页，默认使用网站的综合排序。当前实现不自动翻页，两次扫描之间短暂出现或未进入结果页的商品可能漏报。
- 发现登录、安全验证或访问限制时暂停全部监控，需人工查看监控页并处理，再回设置页开始。卡片结构无法确认时暂停对应条件，关闭某组搜索标签也会暂停该组。
- 每组保留最近 20,000 个已记录的商品 ID。同一商品改价按同一个 ID 去重；之前未匹配、后来进入价格区间的商品可以触发通知。
- 修改某组关键词或价格范围会重建该组基线，修改间隔则保留去重记录。更换公共机器人地址会重建所有组的基线。
- 每批最多合并 10 件商品，收到飞书成功回执后标记完成。发送失败会暂停该组并保留待发送记录。网络超时或浏览器意外退出时送达可能不确定，恢复前可先检查群消息，恢复监控会补发未确认批次。
- 浏览器重启或重新加载扩展后，需要重新开始监控。升级文件时保留原安装目录，点击扩展管理页的刷新按钮，再重新打开设置页。旧版已保存条件、凭据和去重记录会迁移。

## 数据保护

扩展直接读取普通网页已渲染的商品卡片。登录由 Chrome 和闲鱼维护，代码无需导出 Cookie，也不会调用闲鱼私有接口或处理验证码。

Webhook 和签名密钥保存在扩展专属的本地存储中，仅扩展可信页面可以访问，网页读取脚本没有存储访问权。凭据不会进入商品页面、Chrome 同步存储或通知正文。飞书请求关闭附带凭据、来源及重定向，仅接受官方 V2 机器人地址。

本地存储依赖操作系统账户保护。发布或反馈问题时，请避免分享 Chrome 个人资料、扩展存储和包含凭据的截图。仓库仅包含程序、合成测试数据和说明。

## 开发与测试

开发测试使用 Node.js 18.20 或更新版本，从仓库根目录运行：

```sh
node --test tests/*.test.cjs
```

| 文件 | 功能 |
| --- | --- |
| `extension/reader.js` | 识别搜索结果区域、数字商品 ID、标题和独立挂牌价 |
| `extension/background.js` | 管理多组条件、专用标签、计划和状态 |
| `extension/stability.js` | 在扩展后台等待页面结果稳定 |
| `extension/monitor.js` | 校验条件、匹配、去重及待通知记录 |
| `extension/feishu.js` | Webhook 校验、签名及消息发送 |
| `extension/options.html` | 本地配置入口 |
| `tests/` | 使用合成页面和模拟飞书响应的本地回归测试 |

已用真实闲鱼搜索页检查商品卡片字段。自动化测试覆盖多组调度、旧数据迁移、空白默认条件、价格解析、验证暂停、去重、失败补发、签名和脱敏。设置页使用模拟交互验证，真实环境的登录及收件情况需通过预览和测试消息核对。
